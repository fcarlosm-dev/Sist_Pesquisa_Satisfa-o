## 📖 Sobre o Projeto

O **Pesquisa de Satisfação do Cliente** é um sistema simples desenvolvido para **coletar, armazenar e exibir os resultados de uma pesquisa de satisfação** sobre o atendimento prestado por uma empresa.

O programa permite que seja registrado múltiplos clientes em sequência, capturando informações de **nome**, **idade** e **opinião de atendimento**, classificadas em três categorias:

| Código | Opinião       |
|:------:|:------------- |
| 1      | 🟢 EXCELENTE |
| 2      | 🟡 BOM       |
| 3      | 🔴 RUIM      |

Ao final da coleta, o sistema apresentará um **resumo estatístico completo** com contagem, percentuais, média de idade e as opiniões predominantes.

---

## 🎯 Objetivo

- Praticar o uso das **estruturas de repetição** (`while` e `for`) em Python.
- Aplicar conceitos de **listas**, **validação de dados** e **tratamento de exceções**.
- Simular um cenário real de **coleta e análise de dados de pesquisa**.
- Gerar **relatório visual** no terminal de estatísticas importantes.
